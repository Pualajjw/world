# 手机访问

[返回 README](../README.md) · [功能总览](../README.md#功能)

手机浏览器打开同一个 DSH 后台：共用会话、文件、日记和待办，窗口布局和未保存草稿各自独立。视口窄于 600px 时自动切换手机桌面。

## 手机扫码连接

电脑打开开始菜单 →「手机连接」，用手机扫码即可打开 world 手机页面。手机和电脑连接同一个 DSH 后台，共用会话、文件、日记和待办；各自的窗口布局和未保存草稿独立。二维码在本地生成，尺寸为 240×240 CSS px，无新增第三方运行依赖。

默认使用实际局域网接口及 TCP `53319` 端口，点击入口后才监听。`0.2.91` 起，未配置 `WORLD_MOBILE_HOST` 时显示网卡名称和 IP 的下拉选择：只有一个地址时自动生成二维码，多个地址时选择后生成；重新打开时沿用上次选定的地址（`0.2.105` 起这份选择也写在磁盘上，重启后不必重选）。切换地址不打断已连接的手机。手机需能访问所选地址；Windows 防火墙需允许该端口，插件不会自行修改防火墙。二维码收起不影响已连接手机。

`0.2.105` 把二维码做成**长期有效**：配对密钥写在 `<DSH_HOME>/world/mobile.json`（`0600`），重启 DSH 后同一个网卡、同一个端口上生成的二维码**逐字节相同**，手机也不用重扫——浏览器里那份 Cookie 值就是这把密钥，重启后 world 会自己重新向本机 DSH 换一次上游凭据再继续转发。代价是这条链接相当于一把长期钥匙：拿到链接的人扫码即可进入 world，所以弹层里写明「长期有效」，并留了「重置链接」（二次确认）作为唯一的吊销手段——重置会换掉密钥、让旧二维码和旧 Cookie 一起失效。首次读密钥文件如果因为权限失败会直接报错，不会悄悄换一把新的（否则用户手上的二维码就废了）。

多网卡或自定义部署可在启动 DSH 的环境中设置以下变量：

| 环境变量 | 用途 |
| --- | --- |
| `WORLD_MOBILE_HOST` | 可选的固定网卡 IP；配置后优先使用，未配置则在手机连接弹层下拉选择 |
| `WORLD_MOBILE_PORT` | 监听端口，默认 `53319`，`0` 为随机端口 |
| `WORLD_MOBILE_ORIGIN` | 已有公网/VPN/HTTPS 入口的根地址，不含子路径；该地址必须实际可达 |
| `WORLD_MOBILE_CERT` / `WORLD_MOBILE_KEY` | 可选 PEM 证书和私钥文件，同时提供后使用 HTTPS |

默认 HTTP 入口用于可信局域网；跨网访问需要现有可达网络和可信 HTTPS 入口。填写对外地址不会自动穿透网络。手机以内置 owner 身份访问，原有沙箱与审批继续有效；首次配对无需输入电脑账号。

聊天页走同源转发，避免手机访问自己的 localhost。内置浏览器使用 iframe 兼容模式，不能嵌入的网站需在手机浏览器直接打开。手机浏览器的剪贴板等功能还受 HTTPS 和浏览器权限限制。

验证：`npm test`、`npm run test:browser`；`DSH_TEST_CLI` 指向已有 `dsh.cmd` 后运行 `npm run test:mobile`，在独立测试目录验证扫码连接、真实 DSH 页面、WebSocket、共享中文待办、刷新和聊天 SSE；再跑 `node tests/mobile-restart.mjs`，它用同一个 `DSH_HOME` 起两次真实宿主，断言第二次的二维码逐字节相同、手机带着重启前的 Cookie 直接进 world（web 端口变化证明确实重启过）。`npm run test:qr` 使用开发机 Python/OpenCV 独立解码二维码，不增加插件运行依赖。

## 手机桌面

`0.2.88` 起，宿主视口宽度 **≤600 CSS px** 时自动切换手机桌面，支持 **360×640px**：应用图标每行四个、单击或触摸打开，顶部显示时间，底部提供全部应用、返回桌面和应用切换。应用铺满标题栏与底部导航之间的区域；后台窗口和编辑内容保留，浏览器网页视图在后台暂停显示。图标较多时桌面可纵向滚动。

放大到 600px 以上恢复桌面布局；缩放视口不会覆盖桌面窗口的位置、尺寸和图标摆位。VSCode 的侧栏在手机模式覆盖编辑区，日记和待办改为上下排列，继续沿用原有编辑及保存入口。

桌面版外窗的最小尺寸由 DeepSeek Harness 宿主控制：当前本机宿主为 **520×600px**。world 在该宽度下也会切换手机样式；真正把外窗缩到 360px 需要宿主支持。网页视口不受这一原生窗口限制。

自检：`node tests/phone-browser.mjs`，在 `tmp/phone-shots/` 生成 360px 手机桌面、应用和切换器截图；完整浏览器回归也包含手机模式。

## 随 World 启动手机连接

**手机连接自启动**：选好网卡、生成二维码后，勾选「随 World 启动手机连接」即保存。下次启动会等待网页入口就绪并监听已选地址，不弹配置窗口；网卡不可用时不会换一张网卡监听。
