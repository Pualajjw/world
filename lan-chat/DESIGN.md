# 局域网聊天 · 界面设计规格

> 先看界面：双击 [`prototype.html`](./prototype.html)。它是完整自包含的可点原型：world 桌面壁纸 + 一个应用窗口，里面所有会话、消息、设备数据都是设计用的示例数据，不需要启动任何服务。
>
> 静态预览图：`preview-light.png`（浅色）/ `preview-dark.png`（深色），都是浏览器实测截图。
>
> 界面源码只有一份：`app.html` + `app.css` + `app.js`。原型由 `node build-prototype.mjs` 把三者内联生成；真实运行时由 `server.mjs` 直接托管 `app.html`，所以设计稿与成品**像素一致**，不会出现「原型好看、上线变样」。

## 1. 设计目标

| 目标 | 做法 |
| --- | --- |
| 好看 | 浅色留白 + 靛蓝到紫的渐变主色、12~18px 圆角、两级柔和阴影、渐变头像、细描边分隔；深色一键切换 |
| 操作简单 | 三栏一眼看全：「和谁聊 / 聊什么 / 谁在线」；私聊从通讯录点一下就开；发消息只有 Enter 一个动作 |
| 一眼看懂「局域网」 | 右栏常驻雷达扫描动画 + 设备列表，直接显示对方机器名、IP 与 world 插件版本 |
| 不骗人 | 界面上每个按钮都有真实行为；没有语音、文件传输、已读回执这类首版没实现的占位控件 |

## 2. 整体形态

应用以 world 桌面的一个独立窗口出现：外层是 world 同款深蓝缎带壁纸、深色标题栏（`38px`）和最小化 / 最大化 / 关闭三键、48px 任务栏；窗口内是浅色聊天界面。这样它和已有的 DSH 窗口、VSCode 窗口在视觉上是同一套桌面语言。

- 原型窗口：`min(1200px, 94vw) × min(760px, 88vh)`，圆角 `14px`，阴影 `0 32px 80px rgba(0,0,0,.58)`
- 装进 dsh 后：窗口铺满 world 的插件窗口内容区，标题栏交给 world 的窗口框，应用内布局不变

## 3. 布局与尺寸

```
┌─────────────────────────── 应用窗口 ───────────────────────────┐
│ 左栏 274px        │ 中栏 弹性                │ 右栏 258px      │
│ 品牌 38px logo     │ 会话头 68px              │ 会话信息卡       │
│ 在线胶囊 / 搜索框  │ ─────────────────────── │ 公告卡           │
│ Tab 消息/通讯录/群 │  日期分隔                │ 雷达 + 设备列表  │
│ 会话列表（滚动）   │  头像 + 气泡（左/右）    │ 成员（在线/离线）│
│ 新建群聊 / 我的资料│ ─────────────────────── │ 安全说明         │
│                    │ 工具条 + 输入框 + 发送   │                 │
└─────────────────────────────────────────────────────────────────┘
```

| 元素 | 数值 |
| --- | --- |
| 会话头像 | `38×38`，圆角 `12`；列表内小头像 `30`，资料卡 `52` |
| 在线状态点 | `11px`，2px 同底色描边；绿色 `#22c58b` / 灰 `#b9c3d2` |
| 搜索框 | 高 `36`，圆角 `11`，聚焦时 3px 主色光晕 |
| Tab | 高 `29`，选中白底 + 阴影 + 主色文字 |
| 会话行 | 高约 `56`，选中时白卡片、左侧 3px 渐变条、未读数字徽标 |
| 会话头 | 高 `68`，34px 圆形图标按钮（搜索 / 成员 / 刷新） |
| 消息气泡 | 最大宽 `min(66%, 520px)`，圆角 `16`；自己一侧下角收 `5px`；内边距 `10/14`，行高 `1.65` |
| 消息节奏 | 两条独立消息间距 `14`；同一人连续发言间距 `5`，续接气泡藏头像、正文左缩进 `39`；气泡圆角只收最后一条的下角 |
| 输入框 | 圆角 `14`，textarea 自适应 `34~120px`，发送键 `38×38` 渐变方形；输入为空时按钮转为灰面禁用态 |
| 右栏卡片 | 内边距 `13`，圆角 `14`，卡片间距 `10`；成员卡不设内部滚动，随整栏滚动 |
| 雷达 | 高 `72`，3.4s 匀速扫描，光点数量 = 在线设备数（最少 3 个装饰点）；设备列表只列在线设备 |

## 4. 视觉 token

| 项 | 浅色（默认） | 深色 |
| --- | --- | --- |
| 应用底 / 左栏 / 聊天区 / 右栏 | `#ffffff` / `#f7f9fd` / `#fbfcff` / `#f8faff` | `#141b28` / `#182031` / `#111826` / `#161f2e` |
| 文字 / 次要 / 弱化 | `#17233c` / `#7f8ca5` / `#a9b4c8` | `#e9eef9` / `#93a0b9` / `#6f7c96` |
| 描边 | `#e8edf6` | `#26324a` |
| 抬升面 `--lc-raised` | `#ffffff`（选中 Tab / 会话卡 / 右栏卡片 / 弹层） | `#202a3d` |
| 轨道 `--lc-track` | `#eef1f8`（Tab 底槽） | `#1b2436` |
| 输入面 `--lc-field` | `#ffffff`（搜索框 / 图标按钮） | `#1d2637` |
| 主色 / 副色 / 浅底 | `#3b6ef6` / `#7a5cff` / `#eaf0ff` | `#6f9bff` / `#a18cff` / `#202c46` |
| 自己的气泡 | `linear-gradient(135deg,#4c86ff,#6d5bff)` + 白字 | 同色系略降饱和 |
| 对方气泡 | 白底 + 细描边 + 轻阴影 | `#202c40` |
| 在线绿 | `#22c58b` | 同 |
| 字体 | `Segoe UI Variable Text → Segoe UI → Microsoft YaHei UI → system-ui` | 同 |
| 阴影 | `0 12px 34px rgba(30,58,110,.10)` | `0 14px 36px rgba(0,0,0,.38)` |

**窗口外壳（壁纸 / 标题栏 / 任务栏）是固定深色**，不随应用主题变化，避免深色主题下深上加深。所有 CSS 变量以 `--lc-` 前缀、选择器以 `lc-` 前缀隔离，不依赖也不污染 world 的主题变量。

**层级只用三档，且必须「越靠前越亮」**：`--lc-track`（凹槽，如 Tab 底）→ 应用面（左栏 / 聊天区）→ `--lc-raised`（浮起，如选中的 Tab、会话卡、右栏卡片、弹层）。输入类控件统一 `--lc-field`。深色主题里这三档都比应用底 `#141b28` 更亮，这样「选中 = 浮起来」在任何主题下都成立；早期版本直接让选中态用应用底色，结果深色下选中的 Tab 比它的底槽还暗，看起来像挖了个洞。

## 5. 交互地图

| 操作 | 结果 |
| --- | --- |
| 左栏点会话 | 切换会话、清未读、消息滚到底 |
| Tab「通讯录」→ 点某人 | 自动建立并打开私聊，无需先加好友 |
| Tab「群聊」/「新建群聊」 | 弹窗填群名 + 勾选在线成员 → 建好直接打开，并发一条系统消息 |
| Enter / Shift+Enter | 发送 / 换行；输入框随内容长高；只有空白字符时发送键保持禁用 |
| 😊 / @ / ⚡ 三个工具键 | 统一线性图标（17px 描边），分别是表情面板、@ 成员、四条常用语，点一下插进输入框；搜索框非空后搜索键上的 `/` 提示自动让位 |
| 搜索框 / `/` | 实时过滤会话、成员、机器名、IP；按 `/` 直接聚焦 |
| 会话头「成员」 | 收起 / 展开右栏；「刷新」重新拉取在线状态 |
| 右上角主题键 | 浅 ↔ 深主题，图标在月亮 / 太阳之间切换，选择记在浏览器本地 |
| 点左下「我」 | 改昵称，其它设备会看到新名字 |
| 标题栏三键（原型） | 最小化到任务栏、最大化、关闭；双击任务栏按钮或桌面图标还原 |

群聊与私聊共用同一套消息区：群里气泡上方显示发送者昵称，私聊不显示；系统消息（建群、上线提示）居中灰字；`@某人` 在气泡里高亮。

## 6. 状态与动效

- 消息进入：`240ms` 淡入上移；列表选中、按钮 hover 都是 `140~180ms` 过渡
- 在线绿点 `2.2s` 呼吸光晕；雷达 `3.4s` 匀速扫描
- 对方正在输入：工具条右侧文字提示（demo 里 1.6s 后自动回一条）
- 未读徽标用珊瑚红渐变，选中会话后清零
- **贴底跟随**：消息区 `overflow-anchor: none`（否则浏览器滚动锚定会自己改 `scrollTop`，把「用户往上翻」和「新消息进来」混成一件事）。滚到底时用 `scrollTo({ behavior: 'instant' })` 跟随，不能用 `scrollTop = …`，那会被 CSS 的 `scroll-behavior: smooth` 接管，快速连发时肉眼看得出拖影。用户主动往上翻超过 `40px` 就解除跟随，直到重新滚回底部
- **发送键三态**：无会话 / 输入为空 / 只有空白 → 灰面禁用，有内容才亮起渐变；按键高度固定 `38`，禁用态不改尺寸，避免输入时按钮跳动
- **键盘可见焦点**：`:focus-visible` 才画 2px 主色描边，鼠标点击不留圈
- **空态居中**：会话里一条消息都没有时，占位文案在消息区垂直居中，而不是贴着顶部孤零零一行
- `prefers-reduced-motion` 下关掉淡入、雷达旋转与呼吸光晕，只保留即时状态变化

## 7. 响应式

| 宽度 | 处理 |
| --- | --- |
| `> 1080px` | 完整三栏 |
| `720~1080px` | 收起右栏，保留会话 + 聊天两栏 |
| `< 720px` | 只保留聊天区，窗口铺满 |

## 8. 取舍

1. **不做假功能**：语音、视频、文件、已读回执、消息撤回首版没有，界面上就不放按钮；右上角三个按钮都是真的（搜索 / 切成员 / 刷新）。
2. **发现结果常驻右栏**：不藏在设置里，因为「能不能看到局域网里谁装了 world」是这个应用最需要被确认的一件事。
3. **不做独立好友体系**：通讯录就是发现到的设备列表，点开即私聊，把操作步骤压到最少。
4. **私聊/群聊同一套组件**：只靠 `kind` 决定头像、昵称、成员面板和消息转发目标，减少两套 UI 的分叉。

## 9. 与实现的关系

| 文件 | 作用 |
| --- | --- |
| `prototype.html` | 自包含界面设计稿 + 可点 demo（本轮先看它） |
| `app.html` / `app.css` / `app.js` | 唯一一份界面源码，demo 与 live 共用 |
| `server.mjs` | 局域网发现、消息总线、静态托管 |
| `plugin.js` / `client.js` | 把应用挂进 dsh，world 开始菜单自动出现入口 |
